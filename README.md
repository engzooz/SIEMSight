SIEMSight : Next-Gen Rule-Based Log Analysis & Threat Detection Engine

SIEMSight is an extensible, Python-driven SIEM engine engineered to process server logs, correlate security events, assign risk severity, and export structured JSON security reports for SOC analysts

 Key Features
  Multi-Threat Pattern Matching:** Detects SQLi, XSS, Path Traversal, and Brute-Force attacks
  Risk Scoring Mechanism:** Categorizes events by severity (`CRITICAL`, `HIGH`, `MEDIUM`)
  Structured JSON Reporting:** Generates automated SIEM reports ready for integration with dashboard tools
  Object-Oriented Architecture:** Designed for easy expansion and custom threat rule integration
